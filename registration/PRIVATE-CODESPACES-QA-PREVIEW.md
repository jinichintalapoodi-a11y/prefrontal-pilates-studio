# Private Codespaces QA preview — Pilot RC1

**Status:** Prepared, but **not launched**. The GitHub connection available to this project cannot create/manage Codespaces or verify forwarded-port visibility. No live private QA URL exists until the founder launches a Codespace.

## One-time founder steps

1. Open [the RC1 branch](https://github.com/jinichintalapoodi-a11y/prefrontal-pilates-studio/tree/release/pilot-mvp-1-1-rc1) while logged in to GitHub.
2. Select **Code → Codespaces → Create codespace on release/pilot-mvp-1-1-rc1**. Check Codespaces quota/billing before creating; stop if the account asks for a paid upgrade or unapproved charges.
3. The `.devcontainer/devcontainer.json` configuration prepares a Python container and starts a local static server on port `8000`. Wait for the Codespace terminal to display `Started local Neural Orchard QA server on port 8000.`
4. Select the **PORTS** tab. Check port `8000` **Port Visibility = Private** (only you). Do not switch it to `Public` or `Private to Organization`. If needed, right-click the port → **Port Visibility → Private**.
5. From that row, select **Open in Browser** or copy the forwarded address. The link is generated by GitHub for *your* Codespace; it cannot be determined in advance. Do not post the private link publicly.
6. Open `/index.html` for the landing page, `/Stargaizer.html` for Stargazer (note the intentional filename spelling), and `/Sentinel.html` for Sentinel. From the games, complete a short practice, choose **Exit**, and verify both return buttons and optional feedback.
7. To run source checks, open the Codespace terminal and run `node --test registration/PILOT-RC-STATIC-QA.test.mjs`. The server stays local and does not enable production feedback.
8. Stop the Codespace after testing to limit usage. The test server handles local static files only; it does not deploy to GitHub Pages or send emails.

## Security/release boundaries

The port is intended to be **Private**; confirm actual visibility in the Codespaces UI because the setting may vary by account policy. Private means authenticated Codespace owner only. No published public pilot URL is created.

The email Worker is not running with the static preview. Both `ENABLE_EMAIL_FEEDBACK` and `ENABLE_SYNTHETIC_EMAIL_QA` remain off; no Cloudflare DNS/account changes or fees are authorized. The deferred founder dashboard is not activated.

The founder must explicitly approve any future merge, production deployment, public pilot invitation or real participant feedback collection.
